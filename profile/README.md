# CMS-Enterprise GitHub Organization

CMS-Enterprise is a GitHub organization for collaborating on software projects built by [CMS.gov](https://www.cms.gov) (Centers for Medicare & Medicaid Services). We publish software in this organization along with [CMSgov](https://github.com/cmsgov), [Enterprise-CMCS](http://www.github.com/Enterprise-CMCS), and [DSACMS](http://www.github.com/DSACMS). 

We are open to receiving contributions depending on the project. Please see each repository's CONTRIBUTING.md file for how you can help. More information on all CMS projects is available at our [repository metrics website](https://dsacms.github.io/metrics).

Check out the agency’s [Open Source Policy](https://github.com/CMSgov/cms-open-source-policy) and please suggest any ideas for improvement by sending a pull request.

If you would like to create a new project, use our [repository templates](https://github.com/DSACMS/repo-scaffolder).

If you would like to join the CMS-Enterprise organization, or would like to suggest some others to join, file a ticket in our help desk.
